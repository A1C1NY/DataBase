# 课程简化版后端开发顺序

本文档是当前后端的实施依据。目标是完成一个可演示的数据库课程设计，而不是生产系统。
系统可导入三个 JSON 样例，也可调用真实 API，并以固定坐标每 20 分钟采集一次上海数据。

## 最终技术范围

- FastAPI 提供 REST API 和 OpenAPI 页面；
- SQLAlchemy 2 同步 Session + PyMySQL 访问 MySQL 8；
- Alembic 只维护一份首次建表迁移；
- Pydantic 2 校验请求、响应和样例 JSON；
- JWT + Argon2 完成简单登录和三种角色判断；
- pytest 覆盖时间、配置、解析、登录和主要查询；
- HTTPX 实现两个同步 API Client，APScheduler 实现单进程基础定时采集。
- 不使用 Repository、异步 Session、缓存、重试队列、自动清理和多进程防重。

## 开发环境

```bash
cd backend
source ../.database/bin/activate

python -m pip install -e '.[dev]'
```
