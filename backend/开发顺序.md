# 高德公交站点与线路查询分析系统开发顺序

本文档是根目录 `规划.md` 的逐文件实施清单，适用于从空项目、空数据库开始开发。阶段必须按 0-11 顺序推进；前一阶段的完成标准未满足时，不进入下一阶段。

项目只保留高德公交站点和线路接口：

- `v3/bus/stopname`；
- `v3/bus/linename`，并固定传入 `extensions=all`。
- `v3/bus/lineid`，用户点击未解析摘要时按线路 ID 请求，并固定传入 `extensions=all`。

不得创建上海接口客户端、实时到站、车辆、发车计划、固定坐标采集、Scheduler、缓存、Repository 或 GIS 扩展。

## 开发环境

```bash
cd backend
python3.12 -m venv .venv
source .venv/bin/activate
unset PYTHONPATH
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

数据库使用 MySQL 8、InnoDB、`utf8mb4`、`utf8mb4_0900_ai_ci`。正式结构只能通过 Alembic 迁移创建，应用启动时不得调用 `Base.metadata.create_all()`。

### 事务顺序

1. 独立短事务创建 `ingestion_runs(status='running')` 并提交。
2. 在内存中完整解析和校验响应。
3. 开启业务事务，upsert 站点和线路，重建该线路站序和轨迹点。
4. 业务成功后提交；失败则完整回滚。
5. 独立短事务更新运行状态和计数。业务失败时仍保留 `failed` 运行记录。

- [x] 新站序和轨迹记录保存本次 `ingestion_run_id`；站点和线路更新 `last_ingestion_run_id`。

- [x] `GET /api/lines/{id}`、`/stops`、`/map` 优先查询数据库。
- [x] `GET /api/lines/by-amap/{amap_line_id}` 用于独立 ID 查询或点击未解析摘要；本地未命中或站序/轨迹不完整时调用 `lineid`。
- [x] `GET /api/lines/by-amap/{amap_line_id}?refresh=true` 强制调用 `lineid` 刷新已有线路。
- [x] 地图响应包含线路 `LineString`、有序站点 `Point`、起终点和坐标转换元数据。
- [x] 补数成功响应包含 `data_source='amap'` 和 `ingestion_run_id`；本地命中为 `data_source='database'`。

### 错误契约

- [x] 本地和高德都无结果：`404 NOT_FOUND_AFTER_AMAP`。
- [x] Key 缺失、网络或超时：`503 AMAP_UNAVAILABLE`。
- [x] 高德业务失败：`502 AMAP_BUSINESS_ERROR`。
- [x] 输入非法：`422`；无权限：`403`。
- [x] 上游失败不留下半条业务数据，但保留失败运行记录。

### 完成标准

frontend/src/views/        # 搜索、详情、收藏、分析、管理
frontend/src/components/   # 地图、站序、热力图、图表

### 页面顺序

1. 登录/注册和当前用户。
2. 站名搜索、结果列表和站点详情。
3. 站点途经线路、线路详情、站序和线路地图。
4. 收藏站点和收藏线路。
5. 站点/线路密度热力图。
6. 站点访问排行和指定站点时间分布。
7. 管理员账号、基础数据状态和导入记录页面。

### 实现清单

- [ ] MapLibre 使用正式配置的 WGS84 底图；后端 GeoJSON 已转换后再渲染。
- [ ] 地图不可用时站点列表、线路站序和收藏仍可操作。
- [ ] 线路站点使用稳定图层和点击事件，点击详情携带 `entry_point=line_map`。
- [ ] 热力图使用站点/线路分段切换，展示指标名称、网格大小和当前数据覆盖范围。
- [ ] 明确区分空结果、`NOT_FOUND_AFTER_AMAP`、上游不可用和权限不足。
- [ ] 前端路由守卫用于体验，后端 403 始终是最终权限判断。
- [ ] 覆盖桌面和移动端布局、加载、空数据、失败与重复点击状态。

### 端到端场景

1. 数据库为空时按站名查询，高德补入后返回站点。
2. 打开站点详情，补齐途经线路并写入一条访问事件。
3. 打开线路地图，显示方向轨迹和有序站点；点击站点进入详情。
4. 第二次查询同一站点和线路时不调用高德。
5. 添加/取消站点和线路收藏。
6. 分析师查看两种热力图、访问排行和时间分布。
7. 管理员完成账号管理并查看导入记录。
8. 地图服务失败时，列表和详情仍可使用。
